# LDA Figure Index

`figures/lda_workflow.png` is a manually-authored schematic of the analysis
pipeline stages (corpus → preprocessing → dictionary/model selection →
robustness/human evaluation), numerically consistent with the values in
`reports/FROZEN_MANUSCRIPT_VALUES.md`. It is not generated by a script —
flagged here rather than claimed as script-regenerable.

All other figures are generated by `src/make_manuscript_figures.py`, which reads every
plotted number directly from the frozen result files listed below (no value
is hand-typed except where noted as "matches source"; every such value was
diffed against `reports/FROZEN_MANUSCRIPT_VALUES.md` before this index was
written). Style: grayscale only, serif (Times New Roman), vector PDF +
450 dpi PNG, white background, tightly cropped. No figure titles are baked
into the images; captions below are for LaTeX.

## Not produced

- **Optional Figure S3 (full-text length sensitivity, Panel A scatter)** was
  **not generated**. The aggregate correlation (`results/fulltext/length_sensitivity_correlation.csv`,
  k=4: Pearson r=0.3582, p=0.00315) and the length-balanced comparison
  (`results/fulltext/length_sensitivity_comparison.csv`, k=4: JS=0.938,
  ARI=0.945, NMI=0.936) are both verified and available, but no saved result
  file contains the per-document (length, assignment-confidence) pairs
  needed for the Panel A scatter — `models/fulltext/` holds no persisted
  per-document topic distributions. Recomputing those points would require
  re-running inference against the frozen model, which was out of scope per
  the "do not rerun / do not approximate" constraint. If this panel is
  wanted, the per-document scatter data must first be exported from the
  frozen model as its own saved result file; Panel B (the length-balanced
  bar comparison) could be produced immediately from the existing CSV if
  needed.
- pyLDAvis, t-SNE, UMAP, word clouds, and per-coherence-measure figures were
  intentionally not created, per the figure brief.
