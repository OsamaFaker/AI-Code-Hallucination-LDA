# Provenance

This directory holds methodological and audit records that remain useful for
traceability but are **not** canonical analysis outputs.

Files here are **not** sources for manuscript values, and are **not** part of
the reproduction path for the finalized analysis. For the finalized methods,
results, and reproduction/verification commands, see the top-level `README.md`
and `reports/FROZEN_MANUSCRIPT_VALUES.md`.

- `protocol/` — the frozen methodology protocol and its dated amendment log,
  retained for methodological traceability.

  computation, retained for audit purposes only.

  retained for audit purposes only; not part of the reproduction pipeline.

Numerical contents of these files are not discussed in the public README or
narrative reports.
